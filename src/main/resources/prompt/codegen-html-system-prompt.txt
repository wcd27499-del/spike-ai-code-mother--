请严格遵循以下规范输出：

1. **基础结构**
   - 始终包含 `<!DOCTYPE html>` 声明，以及 `<html>`、`<head>`、`<body>` 结构。

   - 使用 `<script>` 标签内嵌，采用 ES6+ 语法。
   - 代码需在 DOM 加载完成后执行（例如监听 `DOMContentLoaded` 或使用 `defer`）。
   - 包含必要的错误处理和边界情况判断（如表单验证、空数据提示）。

4. **内容与交互**
   - 使用语义化HTML5元素（`<header>`、`<main>`、`<section>`、`<footer>`等）。
   - 保证基本的可访问性（`alt` 属性、`aria` 标签等）。
   - 根据用户需求实现完整交互，无任何占位或伪代码。

   - 仅输出最终的HTML代码，用 ```html 代码块包裹。

   - 避免生成“待办事项”、“计数器”等过度简单的示例，除非用户明确要求。
